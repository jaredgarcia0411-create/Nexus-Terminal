## Anti-Patterns Found

### Critical (`1`)
1. **Spies are not restored**: `__tests__/jarvis-client.test.ts:26`
   - `vi.spyOn(globalThis, 'fetch')` is reused while test cleanup currently only calls `vi.clearAllMocks()`.
   - **Fix**: add `afterEach(() => vi.restoreAllMocks())` (or include restore in `beforeEach`) to avoid spy leakage.

### Warnings (`2`)
1. **Implementation detail assertions**: `__tests__/jarvis-macro-summary-component.test.ts:24-25`
   - Tests assert CSS class strings directly (`text-base text-zinc-100`).
   - **Fix**: assert content/roles/labels instead of utility classes.
2. **Markup-coupled component assertions**: `__tests__/charts-tab.test.ts:31`
   - Test relies on exact static markup fragment (`'Screenshot</'`).
   - **Fix**: assert high-level outputs (feature labels, actions present) instead of raw HTML fragments.

## Recommended Actions

**High Priority**:
1. Add `vi.restoreAllMocks()` in `__tests__/jarvis-client.test.ts` and any other test using `vi.spyOn`.
2. Add focused route tests for untested authenticated/authorization/error paths:
   - `app/api/trades/[id]`, `app/api/trades/bulk`, `app/api/tags`, and Schwab flow routes.
3. Add tests for at least one end-to-end path per untested hook (`use-trades`, `use-schwab-status`, `use-trade-filters`).

**Medium Priority**:
1. Expand edge-case coverage for `lib/jarvis` modules (`circuit-breaker`, `rate-limit`, `trade-analysis`) around service failures and recovery behavior.
2. Add tests for validation behavior in route handlers (`invalid payload`, `permission boundary`, `DB unavailable`, `provider errors`).
3. Consolidate repeated `ensureResponse` helper patterns into one local test helper file to reduce duplication.

**Low Priority**:
1. Add semantic assertions in component tests instead of CSS markup checks.
2. Add no-network/snapshot-style unit tests for stream or chart lifecycle fallbacks (especially in component areas now lacking coverage).
3. Add minimal smoke tests for `app/page.tsx` and key tab components before deeper feature expansion.
